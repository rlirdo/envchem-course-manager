# 環境化學課程管理系統

國立東華大學　自然資源與環境學系　**環境化學（NRES20050）115-1**
任課教師：楊悠娟 教授　｜　助教：游豐兆 博士生

一個**單一 HTML 檔**的課程管理系統。沒有伺服器、沒有資料庫、沒有 CDN、沒有外部字型與圖片，
把檔案丟到 GitHub Pages（或直接用瀏覽器開啟）就能用。

---

## 1. 這套系統用來做什麼

| 對象 | 用途 |
|---|---|
| **老師／助教** | 學生名單管理、課程規劃表、每週點名與材料費核算、課程紀錄、鐘點費核銷用授課時數表、成績彙整、備份 |
| **學生** | 看每週教材重點、線上翻閱三節課簡報（附逐字稿）、做線上練習並取得回報用的「成績代碼」 |

### 檔案清單

```
index.html                   ← 系統本體（單一檔，含全部 CSS/JS/教材）
worksheet-ai-module1a.html   ← AI 模組活動 I 學習單（既有檔，系統只連結、不修改）
worksheet-ai-module1b.html   ← AI 模組活動 II 學習單（既有檔，系統只連結、不修改）
SPEC.md                      ← 建置規格書
SELFTEST.md                  ← 驗收自測報告
README.md                    ← 本檔
ppt_titles.json              ← 章節主題骨架參考（系統執行時不需要）
```

> 三個 HTML 檔請放在**同一個資料夾**，學習單連結才點得到。

## 2. 老師模式與學生網址規則

系統用 **hash 路由**判斷身分，沒有帳號密碼。

### 老師模式

| 網址 | 畫面 |
|---|---|
| `index.html`（無 hash） | 老師模式・總覽 |
| `index.html#/admin` | 同上 |
| `index.html#/admin/overview` | 總覽 |
| `index.html#/admin/students` | 學生名單 |
| `index.html#/admin/plan` | 課程規劃表 |
| `index.html#/admin/content` | 課程內容 |
| `index.html#/admin/log` | 教室日誌 |
| `index.html#/admin/backup` | 備份與設定 |

### 學生網址（**不會顯示任何管理分頁**）

| 網址 | 畫面 |
|---|---|
| `…/index.html#/student` | 學生入口（週次總表） |
| `…/index.html#/week/13` | 第 13 週課程內容（教材重點＋簡報＋逐字稿） |
| `…/index.html#/practice/13` | 第 13 週線上練習 |

把 `13` 換成任何週次即可。**總覽分頁的「快速連結」區已經把完整網址列好，按一下就複製**，
可直接貼到 Zuvio／Line 公告。

例（部署到 GitHub Pages 後）：
```
https://rlirdo.github.io/envchem-course-manager/index.html#/student
https://rlirdo.github.io/envchem-course-manager/index.html#/practice/13
```

### 練習成績怎麼回到老師手上

1. 學生在 `#/practice/N` 填座號、姓名 → 作答 → **交卷**。
2. 系統即時評分、逐題顯示對錯與解析，並產生一段 **成績代碼**（base64 編碼的 JSON：週次／座號／姓名／分數／答題明細／時間戳）。
3. 學生按「一鍵複製成績代碼」，貼到老師指定的回報處。
4. 老師在**總覽分頁**的「成績代碼整批匯入框」一次貼上多行（一行一筆），按「匯入成績代碼」。
5. 得分表自動出現。**同一學生同一週有多筆時取最高分**；對不到名單的會列在「待處理」並提示。

> 若師生用同一台電腦／同一個瀏覽器，交卷時也會直接寫進本機資料，不必貼代碼。

## 3. 資料存在哪裡、怎麼備份

- 全部資料存在**瀏覽器的 localStorage**，key 為 `ecm_data`（單一 JSON 物件，含 `schemaVersion`）。
- 資料**不會上傳到任何地方**，只留在這台電腦的這個瀏覽器裡。系統預設**不含任何學生個資**。
- 每次修改即時儲存；右下角會跳出「已儲存 HH:MM:SS」，備份分頁也會顯示最後儲存時間與用量。

### 重要提醒

> **換電腦、換瀏覽器、清除瀏覽資料，資料就不見了。**
> 請養成習慣：每次點完名或期末結算前，到「備份與設定」按一次「匯出完整備份」。

### 備份與設定分頁的四個按鈕

| 按鈕 | 作用 |
|---|---|
| **匯出完整備份（JSON）** | 下載一個 `.json`，含課程設定、學生名單、全部點名紀錄、課程紀錄、成績 |
| **匯入備份** | 選檔或貼上 JSON，**完全覆蓋**目前資料（會二次確認） |
| **匯出課程設定範本** | 只含課程基本資料＋課程規劃表，**不含學生、點名、成績**（見下一節） |
| **清除全部資料** | 雙重確認後回復出廠預設 |

CSV 匯出（名單、出席、規劃表、成績）一律加 **UTF-8 BOM**，Excel 直接開不會亂碼。
唯一要注意的是 Excel 會把座號 `01` 變成 `1` —— 所以**附件一的學生名單建議直接用「列印學生名單」輸出紙本**。

## 4. 如何改成另一門課（範本流程）

系統刻意做成「換課只要換資料」。有兩條路：

### 路線 A：用課程範本（最快，不必改程式）

1. 在現有系統把**課程基本資料**與**課程規劃表**改成新課程的內容。
2. 備份與設定 →「**匯出課程設定範本**」，得到 `ecm_template_YYYYMMDD.json`。
3. 複製一份 `index.html` 到新資料夾（新課程的網站）。
4. 開啟新的 `index.html` → 備份與設定 →「匯入」貼上剛才的範本 JSON。
   - 系統會辨識 `_type: "ecm_template"`，只覆蓋課程資料與規劃表，**保留學生名單與成績**（新系統本來就是空的）。
5. 到「學生名單」貼上新班級的名單即可開課。

> 這條路換得掉：學校／系所／課名／代碼／學年期／教師／助教／時間／地點／總週數／材料費單價／每週日期與主題。
> **換不掉**：每週的教材內容（教材卡、簡報、練習題）——那要走路線 B。

### 路線 B：連教材一起換（要改 `index.html` 裡的 JS）

`index.html` 的 `<script>` 分成六個標好註解的區塊，改課只會動到前四塊：

| 區塊 | 內容 | 換課時要不要改 |
|---|---|---|
| **1 CONFIG** | 系統常數（storage key、分頁定義、出席三態、材料費公式文字、學習單檔名） | 通常只改 `APP_NAME` 與 `WORKSHEETS` |
| **2 DATA** | 課程預設值 `DATA.course`、授課進度預填 `DATA.planPrefill`、章節對照 | **要改** |
| **3 UTIL / STORE / ROSTER** | 工具、localStorage 資料層、名單解析規則 | 不用改 |
| **4 CONTENT** | **各週教材**（`CONTENT[週次] = {...}`） | **要改** |
| **5 VIEWS** | 畫面渲染 | 不用改 |
| **6 ACT / ROUTER** | 互動行為與路由 | 不用改 |

#### CONTENT 的格式

每一週就是一個物件，格式固定，照抄改字即可：

```js
CONTENT[5] = {
  type: 'teach',                  // 'teach'（教學週）｜'exam'（考試週）｜'holiday'（假日週）
  title: '本週標題',
  chapters: '對應課本章節（11E＋中譯對照）',
  reading: '延伸閱讀：…',
  goals: ['本週目標，3–5 條'],
  cards: [                        // 教材重點卡，6–10 張
    { h: '重點標題', b: 'HTML 內文，可用 <sub>／<sup>／<div class="eq">', local: '花蓮／生活連結（可省略）' }
  ],
  slides: [                       // 簡報，≥12 張
    { t: '投影片標題', s: '第一節', cover: true /* 封面才加 */,
      b: ['條列一', '條列二'],
      n: '備忘稿逐字稿。\n一句一行，每句句號後換行。\n第一人稱口語，100–200 字。' }
  ],
  quiz: [                         // 練習題，≥8 題
    { q: '題幹（可含 HTML）', o: ['選項A','選項B','選項C','選項D'], a: 1, e: '解析' }
    //                                                              ↑ a = 正解的索引，從 0 起算
  ],
  links: [ { label: '學習單名稱', href: 'worksheet-xxx.html' } ],   // 可省略
  hw: '作業提醒'                                                    // 可省略
};
```

考試週與假日週更簡單：

```js
CONTENT[11] = { type:'exam', title:'Exam 1', chapters:'…', reading:'…',
                scope:['考試範圍條列'], notice:['應考須知條列'], quiz:[ /* 模擬題 */ ] };

CONTENT[4]  = { type:'holiday', title:'教師節放假', note:'放假說明（可含 HTML）' };
```

#### 實務建議

- **一次改一週**，改完存檔重新整理瀏覽器就看得到，不需要編譯或安裝任何東西。
- 週次沒有建立 `CONTENT[N]` 也不會壞，該週會顯示「本週教材尚未建立」，其餘功能照常運作。
- 改完想確認沒打錯字，可以把 `<script>` 內容存成 `.js` 跑一次 `node --check`（沒裝 Node 就直接開瀏覽器看 Console 有沒有紅字）。
- 逐字稿請維持「**一句一行**」，系統會依換行拆成段落顯示，方便上課時逐句唸。

## 5. 使用小抄

**開學前**：備份與設定確認總週數與基本資料 → 課程規劃表填好每週日期與主題 → 學生名單貼上匯入 → 列印附件一。

**每週上課**：教室日誌選本週 → 系統預設全員出席 → 只點需要改的人（缺席／請假）→ 確認摘要列的材料費份數 → 下方填課程紀錄與照片檔名。

**期中／期末**：課程規劃表「列印授課時數表」核銷鐘點費 → 總覽貼上學生回報的成績代碼 → 匯出成績 CSV → 備份與設定匯出完整備份。

---

## 6. 注意事項

- 本系統**不含任何 API 金鑰**，也不會向外連線。
- 學生名單預設為空；所有個資只存在使用者自己的瀏覽器。
- 各週教材文字為授課團隊**原創編寫**，僅標註對應的課本章節主題與科學事實，
  未逐字複製課本、譯本或出版社簡報內容。延伸閱讀章節對照見各週頁面。
- 若列印功能沒反應，請允許瀏覽器對本站的**彈出視窗**。
