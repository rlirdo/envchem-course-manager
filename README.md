# 環境化學課程管理系統

國立東華大學　自然資源與環境學系　**環境化學（NRES20050）115-1**
任課教師：楊悠娟 教授　｜　助教：游豐兆 博士生

一個**單一 HTML 檔**的課程管理系統。沒有伺服器、沒有資料庫、沒有 CDN、沒有外部字型與圖片，
把檔案丟到 GitHub Pages（或直接用瀏覽器開啟）就能用。

## 1. 這套系統用來做什麼

| 對象 | 用途 |
|---|---|
| **老師／助教** | 學生名單管理、課程規劃表、每週**五態點名**與材料費核算、課程紀錄與**照片牆**、鐘點費核銷用授課時數表、**學期成績結算（含分數撲滿）**、備份 |
| **學生** | 看每週教材重點、**20 分鐘動手做活動**、線上翻閱三節課簡報（附逐字稿）、做線上練習並取得回報用的「成績代碼」 |

### 檔案清單

```
index.html                   ← 系統本體（單一檔，含全部 CSS/JS/教材）
worksheet-ai-module1a.html   ← AI 模組活動 I 學習單（既有檔，系統只連結、不修改）
worksheet-ai-module1b.html   ← AI 模組活動 II 學習單（既有檔，系統只連結、不修改）
SPEC.md                      ← 建置規格書
SELFTEST.md                  ← 驗收自測報告（v1）
SELFTEST_v2.md               ← 驗收自測報告（v2：成績結算／照片／動手做）
README.md                    ← 本檔
ppt_titles.json              ← 章節主題骨架參考（系統執行時不需要）
```

> 三個 HTML 檔請放在**同一個資料夾**，學習單連結才點得到。

系統用 **hash 路由**判斷身分，沒有帳號密碼。

### 老師模式

|---|---|
| `index.html`（無 hash） | 老師模式・總覽 |
| `index.html#/admin` | 同上 |
| `index.html#/admin/overview` | 總覽 |
| `index.html#/admin/students` | 學生名單 |
| `index.html#/admin/plan` | 課程規劃表 |

| `index.html#/admin/backup` | 備份與設定 |

### 學生網址（**不會顯示任何管理分頁**）

| 網址 | 畫面 |
|---|---|
| `…/index.html#/student` | 學生入口（週次總表） |
| `…/index.html#/week/13` | 第 13 週課程內容（**20 分鐘動手做**＋教材重點＋簡報＋逐字稿） |
| `…/index.html#/practice/13` | 第 13 週線上練習 |

把 `13` 換成任何週次即可。**總覽分頁的「快速連結」區已經把完整網址列好，按一下就複製**，
可直接貼到 Zuvio／Line 公告。

例（部署到 GitHub Pages 後）：
```
https://rlirdo.github.io/envchem-course-manager/index.html#/student
https://rlirdo.github.io/envchem-course-manager/index.html#/practice/13
```

### 練習成績怎麼回到老師手上

1. 學生在 `#/practice/N` 填座號、姓名 → 作答 → **交卷**。
2. 系統即時評分、逐題顯示對錯與解析，並產生一段 **成績代碼**（base64 編碼的 JSON：週次／座號／姓名／分數／答題明細／時間戳）。
3. 學生按「一鍵複製成績代碼」，貼到老師指定的回報處。
4. 老師在**總覽分頁**的「成績代碼整批匯入框」一次貼上多行（一行一筆），按「匯入成績代碼」。
5. 得分表自動出現。**同一學生同一週有多筆時取最高分**；對不到名單的會列在「待處理」並提示。

> 若師生用同一台電腦／同一個瀏覽器，交卷時也會直接寫進本機資料，不必貼代碼。

## 3. 資料存在哪裡、怎麼備份

- 全部資料存在**瀏覽器的 localStorage**，key 為 `ecm_data`（單一 JSON 物件，含 `schemaVersion`，目前為 **2**）。
  舊版（`schemaVersion: 1`）的備份或既有資料開啟時會**自動無損升級**：三態出席代碼原樣保留、
  統計數字不變，只補上請假假別、照片中繼、成績結算與撲滿帳本等新欄位。
- 資料**不會上傳到任何地方**，只留在這台電腦的這個瀏覽器裡。系統預設**不含任何學生個資**。
- 每次修改即時儲存；右下角會跳出「已儲存 HH:MM:SS」，備份分頁也會顯示最後儲存時間與用量。

### 重要提醒

> **換電腦、換瀏覽器、清除瀏覽資料，資料就不見了。**
> 請養成習慣：每次點完名或期末結算前，到「備份與設定」按一次「匯出完整備份」。

### 備份與設定分頁的四個按鈕

| 按鈕 | 作用 |
|---|---|
| **匯出完整備份（JSON）** | 下載一個 `.json`，含課程設定、學生名單、全部點名紀錄（含假別）、課程紀錄、練習成績、成績結算欄位、撲滿帳本、成績權重。**不含照片影像** |
| **匯入備份** | 選檔或貼上 JSON，**完全覆蓋**目前資料（會二次確認） |
| **匯出課程設定範本** | 只含課程基本資料＋課程規劃表＋成績權重，**不含學生、點名、成績**（見下一節） |
| **清除全部資料** | 雙重確認後回復出廠預設 |
| **匯出／匯入照片備份（JSON）** | 教室日誌照片影像存 IndexedDB，**不在**完整備份裡，要另外匯出（見 §3.1） |

CSV 匯出（名單、出席、規劃表、成績）一律加 **UTF-8 BOM**，Excel 直接開不會亂碼。
唯一要注意的是 Excel 會把座號 `01` 變成 `1` —— 所以**附件一的學生名單建議直接用「列印學生名單」輸出紙本**。

## 3.1 教室日誌：五態點名與照片牆（v2）

### 出席五態

點一下按鈕依序循環，顏色與字樣都不同：

| 狀態 | 符號 | 顏色 | 計分係數 | 說明 |
|---|:--:|---|:--:|---|
| 出席 | ● | 森綠 | **1.0** | 準時到課 |
| 遲到/早退≤20分 | ◐ | 亮黃 | **0.75** | 遲到或早退在 20 分鐘以內 |
| 遲到/早退>20分 | ◔ | 橘 | **0.5** | 逾 20 分鐘，或早退未事先告知 |
| 缺席 | ✕ | 磚紅 | **0** | |
| 請假 | 假 | 藍灰 | **0** | 可另外註記假別（事假／病假／公假／喪假／生理假／其他） |
| 未點名 | — | 灰（虛線框） | — | 不列入統計 |

- **上課人數＝出席＋兩級遲到**（人有到就有材料），材料費份數＝上課人數＋授課教師人數。
- **出席率的定義不變**（分母含請假與缺席，只計已點名的週），舊資料升級後統計數字完全一樣。
- 「全到」與「清除本週」行為不變。
- 係數只用在「成績結算」分頁的出席原始分：`Σ(各已點名週狀態係數) ÷ 已點名週數 × 100`。

### 照片牆（每週 0–5 張）

- 選檔（可多選）→ 前端自動壓縮（最長邊 1280 px、JPEG 品質 0.8）→ 存入 **IndexedDB**
  （db `ecm_photos`／store `photos`／key `w{週次}_{序號}`）。實測 4.4 MB 原檔壓到約 140 KB。
- 每週上限 5 張，超出會被擋下並提示；每張可寫圖說（建議依 APA：`圖 N　說明（日期，地點）`）、可單張刪除。
- **影像不進 localStorage**，`ecm_data` 裡只留張數與圖說，所以完整備份不會爆量。
- 「列印課程紀錄（參）」會把有照片的週連同縮圖與圖說一起印出。
- 備份與設定分頁有「匯出／匯入照片備份（JSON）」與 IndexedDB 用量顯示。
  **換電腦前請完整備份與照片備份各匯出一次。**

## 3.2 成績結算分頁（v2，只有老師模式看得到）

`#/admin/grades`。一列一位學生，灰底欄為自動計算、白底欄手動輸入，全部即時存檔。

### 權重（依教學計畫表 03wtc，可於「備份與設定」調整）

| 項目 | 權重 | 型式 |
|---|:--:|---|
| 出席 | 9% | **自動**（狀態係數平均 ×100）＋可覆寫 |
| 課堂討論及 Zuvio 雲端回饋 | 6% | 手動 0–100 |
| AI 翻轉及 AI 模組 | 11% | **自動**（練習得分表個人平均）＋可覆寫 |
| 期中考 | 25% | 手動 0–100 |
| 期末考 | 25% | 手動 0–100 |
| 參訪報告 | 12% | 書面 3＋組間互評 4＋組內互評 5 |
| 行動報告 | 12% | 書面 3＋組間互評 4＋組內互評 5 |
| **合計** | **100%** | |

- **自動欄的覆寫**：直接在灰底欄輸入數字即可覆寫（底色轉金黃）；把欄位**清空**就回到自動值。
  「清除全部自動欄覆寫」一鍵還原所有覆寫，手動欄不受影響。
- **分數撲滿**（額外加分）：分頁下方有帳本，可逐筆新增（日期／學生／事由／點數）與刪除。
  規則：口述簡答 1 點、詳答 2 點、上台報告 5 點（附補充資料再 +2）、小組報告提問 2 點、小組全部出席 5 點。
  **累計封頂 200 點，÷20 ＝ 加分，至多 +10 分。**
- **未依 SOP 請假**：手動填次數，**每次總成績 −2 分**。
- **學期總成績** ＝ Σ加權 ＋ 撲滿加分 − SOP 扣分，**下限 0**，同時顯示「一位小數」與「四捨五入整數」兩欄。
- 按鈕：**匯出成績總表 CSV**（UTF-8 BOM，含各欄、撲滿、扣分與總分，末列為全班平均）、
  **列印成績總表**（A4 橫式，含全班平均列與簽章欄）。
- 總覽分頁有「**成績完成度**」摘要卡，逐項顯示各欄已填人數／總人數，可直接連到本分頁。

## 4. 如何改成另一門課（範本流程）

系統刻意做成「換課只要換資料」。有兩條路：

### 路線 A：用課程範本（最快，不必改程式）

1. 在現有系統把**課程基本資料**與**課程規劃表**改成新課程的內容。
2. 備份與設定 →「**匯出課程設定範本**」，得到 `ecm_template_YYYYMMDD.json`。
3. 複製一份 `index.html` 到新資料夾（新課程的網站）。
4. 開啟新的 `index.html` → 備份與設定 →「匯入」貼上剛才的範本 JSON。
   - 系統會辨識 `_type: "ecm_template"`，只覆蓋課程資料與規劃表，**保留學生名單與成績**（新系統本來就是空的）。
5. 到「學生名單」貼上新班級的名單即可開課。

> 這條路換得掉：學校／系所／課名／代碼／學年期／教師／助教／時間／地點／總週數／材料費單價／每週日期與主題。
> **換不掉**：每週的教材內容（教材卡、簡報、練習題）——那要走路線 B。

### 路線 B：連教材一起換（要改 `index.html` 裡的 JS）

`index.html` 的 `<script>` 分成六個標好註解的區塊，改課只會動到前四塊：

| 區塊 | 內容 | 換課時要不要改 |
|---|---|---|
| **1 CONFIG** | 系統常數（storage key、七個分頁、出席五態與係數、成績權重 `GRADE`、照片參數 `PHOTO`、材料費公式文字、學習單檔名） | 通常只改 `APP_NAME`、`WORKSHEETS`、`GRADE` |
| **2 DATA** | 課程預設值 `DATA.course`、授課進度預填 `DATA.planPrefill`、章節對照 | **要改** |
| **3 UTIL / STORE / ROSTER** | 工具、localStorage 資料層、名單解析規則 | 不用改 |
| **4 CONTENT** | **各週教材**（`CONTENT[週次] = {...}`） | **要改** |
| **5 VIEWS** | 畫面渲染 | 不用改 |
| **6 ACT / ROUTER** | 互動行為與路由 | 不用改 |

#### CONTENT 的格式

每一週就是一個物件，格式固定，照抄改字即可：

```js
CONTENT[5] = {
  type: 'teach',                  // 'teach'（教學週）｜'exam'（考試週）｜'holiday'（假日週）
  title: '本週標題',
  chapters: '對應課本章節（11E＋中譯對照）',
  reading: '延伸閱讀：…',
  goals: ['本週目標，3–5 條'],
  cards: [                        // 教材重點卡，6–10 張
    { h: '重點標題', b: 'HTML 內文，可用 <sub>／<sup>／<div class="eq">', local: '花蓮／生活連結（可省略）' }
  ],
  slides: [                       // 簡報，≥12 張
    { t: '投影片標題', s: '第一節', cover: true /* 封面才加 */,
      b: ['條列一', '條列二'],
      n: '備忘稿逐字稿。\n一句一行，每句句號後換行。\n第一人稱口語，100–200 字。' }
  ],
  quiz: [                         // 練習題，≥8 題
    { q: '題幹（可含 HTML）', o: ['選項A','選項B','選項C','選項D'], a: 1, e: '解析' }
    //                                                              ↑ a = 正解的索引，從 0 起算
  ],
  links: [ { label: '學習單名稱', href: 'worksheet-xxx.html' } ],   // 可省略
  hw: '作業提醒'                                                    // 可省略
};

// 20 分鐘動手做活動（寫在 /* ==== CONTENT-INSERT-POINT ==== */ 之後，見 §3.3）
ACTIVITY[5] = {
  name: '活動名稱',
  minutes: 20,
  materials: [ { item: '材料', source: '廢棄品' } ],   // source：廢棄品／農廢／廚餘／家庭常備／教室既有
  steps:     [ { t: '0–4 分', s: '這段時間做什麼' } ],
  chem:      [ { g: 1, t: '對應第 1 條 goal 的化學說明' } ],  // g:0 ＝ 貫穿全週的核心機制
  green:     [ { p: 7, why: '為什麼符合綠色化學第 7 原則' } ],// p 為 1–12
  safety:    [ '安全注意 1', '安全注意 2', '安全注意 3' ],
  observe:   [ '思考題 1', '思考題 2', '思考題 3' ]
};
ACTIVITY_NONE[4] = '本週沒有動手做的原因說明';
```

考試週與假日週更簡單：

```js
CONTENT[11] = { type:'exam', title:'Exam 1', chapters:'…', reading:'…',
                scope:['考試範圍條列'], notice:['應考須知條列'], quiz:[ /* 模擬題 */ ] };
```

#### 實務建議

- **一次改一週**，改完存檔重新整理瀏覽器就看得到，不需要編譯或安裝任何東西。
- 週次沒有建立 `CONTENT[N]` 也不會壞，該週會顯示「本週教材尚未建立」，其餘功能照常運作。
- 改完想確認沒打錯字，可以把 `<script>` 內容存成 `.js` 跑一次 `node --check`（沒裝 Node 就直接開瀏覽器看 Console 有沒有紅字）。
- 逐字稿請維持「**一句一行**」，系統會依換行拆成段落顯示，方便上課時逐句唸。

## 5. 使用小抄

**開學前**：備份與設定確認總週數與基本資料 → 課程規劃表填好每週日期與主題 → 學生名單貼上匯入 → 列印附件一。

**每週上課**：教室日誌選本週 → 系統預設全員出席 → 只點需要改的人（點按鈕循環五態）→ 請假者選假別 → 確認摘要列的「上課人數」與材料費份數 → 填課程紀錄 → 照片牆上傳當週 0–5 張照片並寫圖說 → 上課發言當場登記到「成績結算」的分數撲滿帳本。

**期中／期末**：課程規劃表「列印授課時數表」核銷鐘點費 → 總覽貼上學生回報的成績代碼 → 成績結算分頁填期中／期末／參訪／行動各欄 → 匯出成績總表 CSV 與列印 A4 橫式總表 → 備份與設定匯出完整備份**與照片備份**。

## 6. 注意事項

- 本系統**不含任何 API 金鑰**，也不會向外連線。
- 學生名單預設為空；所有個資只存在使用者自己的瀏覽器。
- 各週教材文字為授課團隊**原創編寫**，僅標註對應的課本章節主題與科學事實，
  未逐字複製課本、譯本或出版社簡報內容。延伸閱讀章節對照見各週頁面。
- 若列印功能沒反應，請允許瀏覽器對本站的**彈出視窗**。
- 動手做活動的材料一律為廢棄品／農廢／廚餘／家庭常備，**零花費**；每個活動都附安全注意，
  涉及火源、刀具、鹼液的步驟請務必先讀過安全欄再動手，並依課程規定於通風處操作。
- 照片存在瀏覽器的 IndexedDB，**清除瀏覽資料會一併消失**，請定期匯出照片備份。
